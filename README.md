# Credit Card Fraud Detection System

A machine learning project that detects fraudulent credit card transactions using Python. This system leverages **Logistic Regression** and **Random Forest Classifier** for classification and utilizes **pandas** and **scikit-learn** for data processing and modeling.

---

## Features

- Detects fraudulent transactions in credit card datasets.
- Compares performance of Logistic Regression and Random Forest Classifier.
- Generates evaluation metrics such as accuracy, precision, recall, and F1-score.
- Provides visualizations for better understanding of the dataset.

---

## Technologies Used

- **Python 3.x**
- **pandas** – Data manipulation and analysis.
- **scikit-learn (sklearn)** – Machine learning algorithms and model evaluation.
- **matplotlib / seaborn** – Data visualization (optional if included).
- **NumPy** – Numerical operations.
